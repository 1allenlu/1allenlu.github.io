# Allen Lu's Portfolio

My personal site, built with Next.js, React, TypeScript, and Framer Motion, and exported as static files for GitHub Pages.

- `npm run dev` starts it locally.
- `npm run build && npm run preview` serves the exported site from `out/`.
- Content (projects, experience, skills) lives in `data/site.ts`.
- The photo gallery is a standalone page in `public/`.
